# GetWarm Online Blanket Store

This is a static website for the GetWarm Clothing & Blanket Store. It showcases a variety of winter products and includes a contact form.

## Deployment

## How to Deploy to GitHub Pages

Follow these steps to publish your website:

1. **Create a GitHub Repository**
	- Go to [GitHub](https://github.com/) and create a new public repository for your project.
	- Initialize the repository with a README file.

2. **Upload Your Project Files**
	- Click the “Upload files” button in your repository.
	- Upload all your project files: `index.html`, `.nojekyll`, and this `README.md`.
	- Commit the changes.

3. **Enable GitHub Pages**
	- Go to the repository’s **Settings** (the cog icon).
	- Scroll down to the **GitHub Pages** section.
	- Under **Source**, select `main` or `master` branch (whichever is your default).

4. **Access Your Website**
	- After a few minutes, your site will be live at:
	  `https://username.github.io/GETWARM-STORE`
	  (replace `username` with your GitHub username and `GETWARM-STORE` with your repository name).

5. **Take a Screenshot**
	- Visit your website, take a screenshot that includes the URL in the browser, and save it to your project folder.
